`gh-repo-alerts`

[![License](https://img.shields.io/github/license/thediveo/gh-repo-alerts)](https://img.shields.io/github/license/thediveo/gh-repo-alerts)

A small CLI tool that scans the Github repos you're the owner of or a
contributor to, listing only repos with open alerts.

To install:

```terminal
go install github.com/thediveo/gh-repo-alerts@latest
```

To run (no flags, no options, nothing):

```terminal
gh-repo-alerts
```
